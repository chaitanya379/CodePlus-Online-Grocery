# 🛒 CodePlus – Online Grocery Management System

**Team Name:** CodePlus

**Team Lead:** Peela Chaitanya Madhavi

**Team Member:** Kuchipudi Stella

## 📌 About the Project
CodePlus is an Online Grocery Management System designed to make grocery selection, cart management, and order placement simple and convenient.

## ✨ Features
- User Login and Registration
- Grocery Product Catalogue
- 60+ Grocery Products
- Product Categories
- Search and Filter Products
- Shopping Cart Management
- Quantity Updates
- Checkout and Order Placement
- Order History

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- MySQL

## 📂 Project Structure
- `frontend/` – HTML, CSS and JavaScript files
- `backend/` – Java Spring Boot application
- `database/` – Database-related files

## 🚀 Project Goal
To provide a simple and user-friendly platform for managing grocery selections and orders.
